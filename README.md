# Calculadora de idade

Página web que calcula a idade em anos a partir da data de nascimento informada. Exercício de estudo de JavaScript e manipulação de datas.

## Stack
- HTML, CSS, JavaScript, Moment.js e Bootstrap 5

## Como executar
Na raiz do repositório, abra `src/index.html` no navegador. As bibliotecas são carregadas por CDN.
